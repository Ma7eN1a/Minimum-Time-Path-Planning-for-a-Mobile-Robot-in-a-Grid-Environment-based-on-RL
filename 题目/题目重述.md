# 网格环境中小车的最短时间路径规划

小车从 10×10 网格的起点 `S` 出发，每次可以向上、下、左、右移动一格。越界时小车留在原位置，障碍格不可进入。目标是避开障碍，以最短时间到达终点 `G`。

## 原地图

每行从左到右对应一行网格。`#` 表示障碍，`.` 表示可通行格。行列从 0 开始，起点为 `(8, 1)`，终点为 `(0, 9)`。坐标配置见[原地图数据](../maps/original.json)。

```text
..#......G
..#.......
....##..##
.....#....
.....#....
..........
.###......
......##..
.S.....#..
.......#..
```

## 任务

1. **建立优化模型和马尔可夫决策过程。** 定义决策变量、目标函数和约束条件，例如以到达终点的步数为最小化目标。给出马尔可夫决策过程的状态空间、动作空间、转移概率、奖励和折扣因子。
2. **分别实现 SARSA 和 Q-learning。** 给出两种算法的伪代码，说明超参数取值及其选择理由，训练小车从起点到达终点的策略。
3. **展示和比较实验结果。** 绘制累积奖励随训练步数变化的曲线，并画出最终策略下从 `S` 到 `G` 的实际路径。用训练曲线比较两种算法的学习速度，用平均抵达步数比较最终策略。另设一张改变障碍位置的地图，比较两种算法在新环境中的规划结果。
