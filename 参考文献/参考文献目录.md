## 最优性验证与实验设计

### R04 — BFS 最短路径的官方算法资料

SEDGEWICK R, WAYNE K. BreadthFirstPaths: Algorithms, 4th Edition companion documentation[EB/OL]. [2026-10-23].

- [作者教材配套文档](https://algs4.cs.princeton.edu/code/javadoc/edu/princeton/cs/algs4/BreadthFirstPaths.html)。
- 拟用于：在无权图中计算按边数度量的最短路径，作为强化学习路径长度的独立基准。
- 对本题的应用建议：每个可通行网格为顶点，相邻可通行格之间为边；在每次移动耗时相同的假设下，用 BFS 的最短边数校验最短步数。
- 使用边界：等耗时是本项目的建模假设；若每步耗时不同，则 BFS 最少边数不再等价于最短时间。BFS 是验证基准，不替代题目要求的两种学习算法。
- 核验：作者、用途、最少边数含义及复杂度已由官方文档确认。无需安装其 Java 实现。

1. 采用的定义、公式、算法伪代码和外部观点，在对应句子、公式或算法说明旁添加引用；仅列在文末不够。
2. 草稿可写 `[@R01]`、`[@R02]`；LaTeX 使用 `\cite{R01}`。最终统一按首次出现顺序转换成 [1]、[2] 等，文末只保留真正使用的条目。
3. 每次实际引用时，在 `引用记录.md` 登记文件、章节/位置、具体用途及原文定位。候选条目不能自动算作“已引用”。
4. 自己选择的奖励、超参数、训练次数及地图改动，应写明是本项目设定；文献不会替这些具体设定背书。
5. 自己生成的训练曲线与结果表标为本项目实验；引用文献只支持方法。复用/改绘外部图片或表格时，在图注/表注说明来源并核查许可。
6. 对障碍改变实验，明确是否重新训练、是否沿用 Q 表和是否继续探索；新地图的可达性与最短步数基准重新计算。此项是本项目实验设计建议。
7. 报告比较训练曲线时明确横轴是累计环境交互步数还是回合数，纵轴是单回合总奖励、累计总奖励还是平滑值。实际优劣由数据决定。
8. 新增文献须验证作者、年份、题名、出处与 DOI/官方链接；不补造页码、卷期、链接或实验结论。
