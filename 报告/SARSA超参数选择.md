# SARSA 超参数选择说明

日期：2026-10-23。默认值与 `sarsa.py / SarsaConfig`、`train_sarsa.py` 一致。除已经确认的环境规则外，其余数值均为本项目选择的初始实验配置，未开展网格搜索，不声称是全局最优参数。

## 1. 固定规则与可调参数

| 参数 | 默认值 | 选择理由 / 性质 |
|---|---|---|
| 每步奖励 | −1 | 已确认模型规则，对应单位耗时；不可在调参中擅改 |
| 折扣因子γ | 1.0 | 已确认模型规则，保持成功轨迹总回报等于负耗时 |
| 单回合上限H | 1000 | 已确认的采样保护上限；超时不等于到达终点 |
| 学习率α | 0.1，固定 | 每次更新修正当前误差的10%；取相对温和步长，以减轻探索动作导致的单次目标波动 |
| Q初值 | 全0 | 不使用地图最短距离先验；对于负回报任务，0相对成功路径的真实负值偏乐观，未尝试动作有机会被探索 |
| ε初值 | 1.0 | 初期四个动作均匀探索，减少早期未学习Q值带来的方向偏好 |
| ε下限 | 0.05 | 后期保留5%的均匀随机动作分支，继续访问较少使用的动作 |
| ε衰减回合数D | 4000 | 前80%的默认训练回合逐步减少探索，后1000回合保持下限 |
| 训练回合数N | 5000 | 作为10×10表格型任务的初始训练预算；是否足够以实测评估决定 |
| 训练种子 | 42 | 便于复现的一次预先指定验证运行；没有筛选最佳种子 |
| 评估ε | 0 | 检查学得的贪心策略；即使无探索，严格并列最优动作仍随机选择 |
| 评估回合数 | 100 | 检查固定Q表的运行表现，不能当作100个独立训练种子 |
| 评估种子 | 训练种子+1000000 | 单独创建随机源，使评估不消耗训练随机序列；默认1000042 |
| 数值精度 | float64 | 使用NumPy存储Q表 [R06]，小地图开销很低 |

固定α=0.1表示持续使用相同步长，并非理论收敛条件中的递减步长。固定非零ε下限也不意味着行为策略最终成为纯贪心策略。因此本项目只根据有限次实验报告表现，不将配置包装为理论最优收敛保证。

## 2. 探索率调度

令回合编号 \(e=0,1,\ldots,N-1\)，则

\[
\varepsilon_e=\varepsilon_{\mathrm{start}}
+(\varepsilon_{\mathrm{end}}-\varepsilon_{\mathrm{start}})
\min\left(1,\frac{e}{D-1}\right).
\]

默认第1回合ε=1.0，第4000回合ε=0.05，第4001至5000回合保持0.05。每回合内部ε不变，下一回合重置环境后才更新ε。

这里的5%是“进入随机动作分支”的概率，不是“选择非贪心动作”的概率，因为随机分支仍可能选到贪心动作。若最大Q值唯一，后期该动作的概率为0.95+0.05/4=0.9625，其余各动作概率为0.0125；这是本项目动作选择逻辑的直接计算。

修改 `--episodes` 不会自动改变 `--epsilon-decay-episodes`。例如仅跑100回合是功能冒烟检查，默认探索率尚未下降到0.05；不能把这种短运行与默认完整训练混为一谈。

## 3. 参数选择与环境假设的区别

SARSA更新方法及采样下一动作的依据见 [R01，第6.4节，式(6.7)]；α、ε调度、训练预算和种子取值是本项目选择，不是照搬教材中另一张地图的最优配置。既定的奖励、γ、碰撞与计时规则保持不变。

SARSA训练阶段学习的是含探索行为下的动作价值；最终ε=0评估改变了执行策略。训练回报与冻结贪心评估结果必须分别报告，不能因为训练仍发生绕路就断言贪心路径不最优，也不能因为贪心路径最短就声称全部Q值已精确收敛。

## 4. 后续参数对比建议（尚未执行）

若第三问需要比较参数影响，可先测试α∈{0.05,0.1,0.2}、ε下限∈{0.01,0.05,0.1}，其余条件保持一致。这些是待检验候选，不应写成已证实的最佳组合。

正式比较SARSA与Q-learning时，应预先确定共同的地图、奖励、交互预算和种子清单。当前接口以回合数控制训练，两个算法即使回合数相同也可能有不同交互步数；日志已记录累计交互步数，不能把同回合数直接称为同样本预算。若采用严格等交互预算，应在实验驱动层同时为两算法加入相同的步数预算与对应截断处理。

建议正式实验至少使用一组预先固定的多个训练种子，例如0至9；默认42只是本次功能验证种子。此安排是本项目后续实验建议，尚未执行。选择参数时与最终报告用的评估种子分开，保留失败和超时记录；不能挑选单次最优结果代表算法平均水平。

本次默认配置已完成一次训练验证，结果见 `问题2_SARSA算法设计与伪代码.md` 第6节及保存的原始日志。它支持当前代码可运行、该次贪心策略达到16步基准，不构成超参数搜索结论。

## 5. 修改方式

在PyCharm的运行配置参数栏填写，或在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe train_sarsa.py --alpha 0.1 --episodes 5000 --epsilon-start 1.0 --epsilon-end 0.05 --epsilon-decay-episodes 4000 --seed 42 --eval-episodes 100
```

无需修改源码即可调整以上算法参数；每次运行都会保存实际配置。γ、每步奖励及1000步上限没有提供命令行调参入口，以落实已确认的模型假设。
