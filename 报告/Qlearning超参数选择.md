# Q-learning超参数选择

## 参数与用途

下表为本项目初始实验设定，不声称经过最优调参，也不把具体数值归于文献推荐。所有代码参数位置均备注中文名称与用途。

| 参数 | 默认值 | 用途及选择理由 |
|---|---:|---|
| episodes | 5000 | 与SARSA保持相同回合预算，覆盖探索率衰减阶段及后续低探索阶段 |
| alpha | 0.1 | 学习率，控制单次修正幅度；沿用SARSA基线，尚未作敏感性检验 |
| epsilon_start | 1.0 | 初期完全随机探索，覆盖四个动作 |
| epsilon_end | 0.05 | 后期保留少量探索，避免直接固定行为动作 |
| epsilon_decay_episodes | 4000 | 前4000回合线性衰减，最后1000回合保持下限 |
| seed | 42 | 训练随机种子，便于复现，不代表该种子具有特殊优势 |
| eval_episodes | 100 | 冻结一个已训练Q表后的重复测试次数，不等价于100个训练种子 |
| Q初值 | 0 | 不使用地图最短距离或路径来初始化 |
| 评估ε | 0 | 关闭随机探索分支；严格并列最大值仍均匀随机选择 |
| 评估种子 | 训练种子+1000000 | 独立评估随机源；默认1000042 |
| window | 100回合 | 绘图尾随平滑窗口，仅改变显示，不影响训练 |
| dpi | 180 | PNG图片清晰度，不影响数值结果 |

奖励−1、γ=1、单位动作耗时1、回合上限1000均是已确认固定环境设定，不在本轮静默调参。

对于从0开始的回合编号e，探索率按本项目规则设置：

\[
\epsilon(e)=1+(0.05-1)\min\{1,\max\{0,e/3999\}\}.
\]

因此第1回合为1、第4000回合到达0.05，并非第4001回合才到下限。配置校验和调度直接继承现有SarsaConfig，Q-learning的默认字段在QLearningConfig中显式列出。

## 选择边界与后续比较

本次同配置基线用于实现验证，不证明参数最优。尽管两算法均训练5000回合，实际环境交互次数不同；不能把“相同回合数”解释成“相同交互预算”。相同seed也不保证随机动作序列完全配对，因为两种训练循环的抽样时序不同。

后续若正式比较，可在共同交互步数范围内观察训练回报，并另设多个训练种子及一致的调参预算，报告训练种子间差异。本轮尚未执行这些扩展实验，不填写推测结果。固定α的本次有限实验不直接套用Q-learning原论文的收敛结论[R02]。

## 实际引用
