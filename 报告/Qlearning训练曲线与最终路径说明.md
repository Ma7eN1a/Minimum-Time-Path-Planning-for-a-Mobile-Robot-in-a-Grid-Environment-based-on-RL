# Q-learning训练曲线与最终策略路径

来源：`outputs/q_learning/design_validation_seed42/`，训练种子42，5000回合。图像与数值均为本项目实际实验，NumPy用于统计[R06]，Matplotlib用于绘图[R07]。与SARSA采用相同的图表口径，不绘制损失曲线。

## 1. 奖励训练曲线

横轴为累计环境交互步数`cumulative_steps`；纵轴为当前单回合奖励之和`episode_return`。每个回合结束时记录一个点，包含碰撞和超时，不是把全部训练奖励一直累加。因每步奖励−1，回合执行T步则回报为−T，这是本项目环境设定的直接结果。

浅蓝为原始5000点；深蓝为最近100回合等权滑动平均，位置对齐窗口末回合的累计步数。仅从第100回合起绘制4901个完整窗口，不使用未来数据。橙色线位于第4000回合结束的累计步数，表示探索率降至0.05。

- 累计训练交互353078步；训练超时40回合，均保留−1000回报。
- 前100回合平均回报−585.20，最后100回合平均回报−16.74。
- 单回合回报范围−1000至−16。
- 已核验所有回报等于负回合步数、累计步数与回合步数和一致、首末平滑值与直接均值一致。

训练曲线含探索动作，不等同于最终纯贪心测试，也不能单凭平滑线宣称严格收敛。

## 2. 最终策略路径

使用保存的Q表及训练时地图快照，以ε=0、评估种子1000042执行首个回合；不更新Q，不挑选最佳轨迹。最大Q值并列时均匀随机打破并列。实际从S到G共16步，无碰撞，奖励−16；BFS独立基准[R04]也为16步，未用BFS路线代替策略执行结果。

坐标为从0开始的(行,列)，左上角为原点：

```text
S(8,1) → (8,2) → (7,2) → (7,3) → (7,4) → (7,5)
→ (6,5) → (5,5) → (5,6) → (5,7) → (4,7) → (3,7)
→ (2,7) → (1,7) → (1,8) → (1,9) → G(0,9)
```

箭头为行进方向，数字为到达步序，S为第0步、G为第16步。Q表前后完全一致，每一步符合贪心转移，轨迹与训练后保存的历史首回合路径一致。该路径并非唯一最短路线；一次轨迹图不是整个状态空间的策略图。

同一Q表的100次评估全部成功，成功耗时均为16步。此结果只对应当前训练种子，不能推出其他训练种子或地图的表现。

## 3. 输出与复现

PyCharm中运行`plot_q_learning_training.py`或`plot_q_learning_path.py`即可显示并保存相应图，默认使用上述已验证实验目录。其他训练结果请用`--run-dir`指定；`--no-show`仅保存不弹窗。

实验目录的`figures/`包含：

- `training_return_curve.png`及`.svg`：奖励训练曲线。
- `training_return_statistics.json`：回报统计及来源路径。
- `final_policy_path.png`及`.svg`：最终策略路径图。
- `final_policy_path.json`：完整轨迹、参数、核验结果和Q表摘要。

已逐图打开PNG检查标题、坐标、原始回报范围、图例及路径箭头；没有裁去低回报或失败记录。重复绘制只更新同名图表产物，不修改Q表或历史日志。
