## 在 PyCharm 中运行

使用本项目 `.venv\Scripts\python.exe` 解释器，打开根目录的 `build_map.py`，右键运行。程序保存地图图片、校验结果并显示绘图窗口；无需新增依赖。

命令行无窗口运行：

```powershell
.\.venv\Scripts\python.exe build_map.py --no-show
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

程序通过自身文件位置定位地图和输出目录，不依赖 PyCharm 的运行工作目录。

生成文件：`outputs/maps/original_map.png`（行列号为零基，障碍位置与题图一致；起终点加色便于查看）、`outputs/maps/map_validation.json`（地图规模、可达性、一条最短路径及步数）。

## 后续训练接口

```python
from gridworld import Action, GridWorld

env = GridWorld()
state = env.reset()
next_state, reward, terminated, truncated, info = env.step(Action.UP)
```

动作编码：0=上、1=下、2=左、3=右。状态为 `(行, 列)`。每次动作奖励−1、耗时1；碰撞停留；到达终点返回 `info['arrival_time']`；未到达时该字段为 `None`。`info['elapsed_time']` 始终记录当前已耗时。

到达终点或1000步截断后必须 `reset()` 再开始下一回合。终点优先于步数上限判定。环境暴露 `gamma=1.0`；折扣因子由后续算法使用，环境本身不执行Q值更新。训练实现不得把 `truncated=True` 自动当成终点将后续价值清零。

规则依据：`模型假设/最终模型假设.md`。当前阶段只建立地图和环境，没有训练 SARSA 或 Q-learning。

## 校验及引用

地图可达性和最短步数采用自行编写的广度优先搜索实现，依据无权图 BFS 最少边数性质 [R04]。该结果仅用于独立校验，不代表强化学习训练结果。

图像使用 Matplotlib 绘制 [R07]。图的障碍布局来自作业题图，坐标标签和起终点配色为本项目添加。
